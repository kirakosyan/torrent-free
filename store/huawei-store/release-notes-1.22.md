# Version 1.22: Huawei AppGallery

Display version **1.22**, Android code **27**, identity **com.torrentfree.app.huawei**,
**ARM64** only, minimum API 23 / Android 6.0. Uses the existing private signing key.

Adds the searchable torrent file picker, saved selections, selected-file progress,
responsive mobile layouts, and the Huawei routing fixes documented after 1.20.
See the [shared release record](../microsoft-store/release-notes-1.22.md) for feature
validation, source tag and package hashes. This release aligns all three stores.
