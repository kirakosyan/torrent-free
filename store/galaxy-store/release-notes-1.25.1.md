# Version 1.25.1: Galaxy preparation

Android **1.25.1 / code 31**, identity **com.torrentfree.app.galaxy**, ARM64 and x86_64.
Prepared locally; **not uploaded, submitted, or published**.

Improved torrent restart, seed limits, proxy/settings handling and progress accuracy.
Completed-file exports work offline, support cancellation and check the space for
the full export. Foreground and completion notifications use monochrome icons.
Generic/untyped torrent inputs use Browse. Localized Android release notes are in
[the shared notes](../google-play/release-notes-1.25.1.txt); the existing Galaxy locale
mapping in `prepare_submission.py` supplies the 24 supported listing languages.

See the [shared preparation record](../microsoft-store/release-notes-1.25.1.md)
for source, package hashes, signing validation and remaining device qualification.
Seller eligibility and device/store handoffs have not been rechecked in this preparation.
